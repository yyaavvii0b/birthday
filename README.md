# A little birthday surprise

Open `index.html` in a browser to start. The site has four pages: home, our moments, a letter, and make a wish.

On the memories page, add four photos to the `photos` folder named `memory-1.jpg` through `memory-4.jpg`. They appear in order beside the four sample captions. Edit those captions in `memories.html` to make the page yours. Keep the names/extensions as written, or update the matching image paths in that page.

The letter opens when its heart seal is tapped. You can personalize the note in `letter.html`.
